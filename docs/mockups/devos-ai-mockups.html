AIChatViewModel is the UI-layer brain for the chat screen. It's a Hilt-injected ViewModel that:

• Collects streaming AI responses via Flow
• Manages chat history persistence

SharedFlow & Hot Streams
A SharedFlow is a hot stream that emits values to all active collectors. Unlike StateFlow, it doesn't have a fixed current value.
Here's how it's used in DevOS AI:
private val _events = MutableSharedFlow<ChatEvent>() val events = _events.asSharedFlow() fun emitScrollToBottom() { viewModelScope.launch { _events.emit(ChatEvent.ScrollToBottom) } }

Found in AIChatViewModel.kt — the same pattern you're learning is used for chat events!

What is the key difference between StateFlow and SharedFlow?
✓
StateFlow always has a current value; SharedFlow does not
B
StateFlow is cold, SharedFlow is hot
C
They are identical except for naming
D

✓ Correct!
StateFlow holds a current state value and replays it to new collectors. SharedFlow is for events that shouldn't be replayed.
